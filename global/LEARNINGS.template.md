# Mistakes & Learnings Log

This file is a running memory of corrections, mistakes, and non-obvious gotchas encountered by AI assistants working in this repository. See `global/instructions/03-learnings-log.md` for the full protocol.

**Before starting a task:** read every entry below.
**After being corrected, or after hitting a non-obvious gotcha:** add a new entry, newest last, using the format below.

```markdown
## YYYY-MM-DD — Short descriptive title

**Context:** What task or area this came up in.

**Mistake / Gotcha:** What went wrong, or what was non-obvious.

**Correct Pattern:** What to do instead, going forward.
```
